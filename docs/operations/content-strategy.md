# Research Strategy

## Positioning

Memory Systems Notes 面向中文技术读者，长期研究 AI 记忆系统的论文、开源实现、工程架构和评测方法。站点目标是像资深工程师公开研究笔记：具体、克制、有来源、有判断。

## Core Columns

- 论文解读：AI memory、long-term memory、memory-augmented agents、RAG memory、context compression、forgetting、personalization。
- 开源项目分析：阅读仓库结构、核心接口、存储层、检索路径、评测脚本和实际可用性。
- 架构优化：比较向量库、知识图谱、摘要记忆、事件日志、用户画像和混合记忆方案。
- 评测与失败模式：记录召回、冲突、污染、遗忘、隐私、成本和延迟问题。

## Publishing Loop

1. 每天收集论文、开源仓库、工程案例和社区讨论。
2. 只有当材料足够支撑一篇有判断的研究文章时才发布。
3. 若当天没有新材料或没有可验证价值，只记录候选线索，不强行写文。
4. 每篇文章必须能回答：它解决什么问题、怎么做、证据是什么、局限在哪里、工程上是否值得采用。

## Voice

写作要像技术大牛的研究分享：少讲情绪和流量，多讲机制、边界、取舍和可复核证据。允许明确表达判断，但不要把猜测写成事实。
