# Content Strategy

## Positioning

AI Agent 实验室面向中文技术读者，记录 AI Agent 如何被构建、部署、运营、审核和复盘。站点以 OpenClaw 和 Codex 为起点，但不局限于单一工具。

## Core Columns

- AI Agent 工程日志：真实任务、工具调用、自动化流程和错误修正。
- 部署与增长：Vercel、GitHub、域名、搜索收录、RSS、站点结构和性能。
- 工具复盘：记录工具边界、适用场景、失败模式和替代方案。
- 广告审核准备：记录原创内容、导航、隐私政策、免责声明和 AdSense 风险控制。

## Monthly Operating Loop

1. 维护 8-12 个候选选题。
2. 每周发布 1-2 篇文章，优先写已经发生的实验。
3. 每月复盘一次搜索收录、内容质量和读者反馈。
4. 申请广告前，至少准备 15 篇以上有实质内容的原创文章，并完成域名、隐私政策和联系渠道。

## Voice

写作要像工程师的现场记录：具体、克制、有判断。允许第一人称，但少用口号。每篇文章都要说明限制条件，不假装自动化万能。
